# Onboard
1. Detect: manifests (package.json, pubspec.yaml, pyproject), framework configs, entry points, top 2 folder levels, CI/Docker, tests. Use search, don't read everything.
2. Summarize in one screen: stack, architecture, key folders, one request path, conventions (naming, errors, git), run/test/build commands, "where to look" table.
3. Mark anything uncertain "unknown".
4. Offer a CLAUDE.md under 100 lines; if one exists, only add to it and show what changed. Write only with Aj's OK.
Do not copy the README or list every dependency.
