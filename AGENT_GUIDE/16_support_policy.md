# Support policy surface

- SUPPORT_POLICY.md in the root ships with every copy — fill the blanks (free period,
  subscription amount, vendor contact) at handover. Do not delete it.
- The same tiers show in-app: Settings -> Report a Problem card in BATHCO_NATURE.html
  (id="report-problem-card"). Contact lines auto-fill from branding config
  support_contact{name,phone,email} — set those in config/active.branding.json.
- If support terms change, update BOTH places.
