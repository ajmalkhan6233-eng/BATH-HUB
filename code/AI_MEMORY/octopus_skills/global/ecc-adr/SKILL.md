# ADR (decision record)
When: Aj picks between frameworks, databases, API styles, auth, hosting, or asks "why did we choose X?" (then read docs/adr/ first).
Never create files without Aj's OK. Draft, show, then write docs/adr/NNNN-title.md and add a line to docs/adr/README.md index.
Format: Title, Date, Status (proposed/accepted/superseded by NNNN), Context (2-5 lines), Decision (1-3 lines), Alternatives (pros/cons/why not), Consequences (good/bad/risks).
Keep under 2 minutes to read. Skip trivia. Mark backfilled decisions with the original date. Link replacement when superseded.
