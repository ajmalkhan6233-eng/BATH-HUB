# Plan (5 lines)
Goal in one sentence. Files new and changed (one module each). Check: how we prove it works. Rollback in one line. Cost: usage small, medium or large, and whether a PC step is needed. AJ's "go" covers only the named job. Discussion and planning first; build after "go".
