# Papers intake (chat reads, the PC loads)
1. Photos in batches of up to 10. Read every figure; mark unreadable ones, never guess.
2. Check line maths and totals (the Rs 400 case). List differences.
3. Write ONE private JSON in PAPERS/ in the format of docs/PAPERS.md. Keep the invoice number in the file name.
4. Show AJ a 5-line summary to confirm. Nothing loads before his confirmation.
5. Loading runs on the PC by task: rehearsal first, backup, all-or-nothing, no doubles (scripts/import_papers.js).
6. Handwritten tags and "free" items are kept as notes for AJ to explain.
